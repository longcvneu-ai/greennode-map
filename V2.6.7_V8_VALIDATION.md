# V2.6.7 Candidate v8 validation

## Field bug reproduced and fixed
Observed field phrase: `tài sản nào phát sinh 2 kỳ rủi ro liên tiếp`.
In v7 this phrase could fall through to the normal current-risk list because the persistent-risk detector depended on word order.

v8 makes persistent-risk routing semantic/word-order independent and adds a one-period integration regression.

## Required regression behavior
For a dataset containing only August 2026, even if August contains current risk cases:
- KPI Persistent Risk: unavailable / requires at least 2 reporting periods.
- Query `tài sản nào phát sinh 2 kỳ rủi ro liên tiếp`: routes to PERSISTENT_RISK.
- Query result: 0 rows.
- User answer: insufficient reporting periods, never the current-risk count.
