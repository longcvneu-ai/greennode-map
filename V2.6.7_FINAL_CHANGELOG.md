# GreenNode Map V2.6.7 Final — pre-deploy candidate

## Final-scope fixes
1. Risk Context remains the deterministic source of truth for analytical questions.
2. Analytical/comparison/recommendation/unsupported-conclusion routing remains on RISK_CONTEXT.
3. Evidence-grounded GreenNode enrichment remains optional; deterministic fallback remains authoritative.
4. Current/latest/explicit/no-dataset period resolution retained and regression-tested.
5. Natural TSBĐ count coverage expanded: `TSBĐ`, `tài sản bảo đảm`, `tài sản đảm bảo`, including province filters and no explicit period (uses current selected/default reporting period for deterministic queries).
6. AI suggestions renamed to **Gợi ý phân tích** and changed to goal-oriented anchors; comparison suggestion only appears when at least two periods exist.
7. Responsive mobile patch reduces map height and improves KPI/AI readability.
8. Map collision patch keeps the asset-count badge top-right at laptop/mobile widths, away from Leaflet +/- controls; legend constrained on small screens.
9. Risk Intelligence answer/guardrail/fallback behavior from V2.6.7 retained; no technical error should replace deterministic analysis when enrichment fails.

## Candidate v10 — Ranking invariant / tie hardening

- Added a single ranking invariant in `RiskContext`: ranking now carries all co-leaders, the shared value, tie flag and leader count for both province and risk type.
- Analytical formatter no longer selects the first row when leaders are tied. Conclusion, evidence and P1/P2 preserve all co-leaders.
- AI enrichment is suppressed from the final answer when a ranking tie exists, preventing the LLM from breaking a deterministic tie.
- GreenNode enrichment prompt explicitly forbids selecting one co-leader without a deterministic tie-break criterion.
- Deterministic query formatter now preserves ties for generic RANK, COUNT, TOTAL_VALUATION and TOTAL_DEBT rankings.
- Added `test:ranking-invariant` and inserted it into `test:final-regression`.
- Real 30K Excel regression now asserts the known tie: 4 provinces x 300 cases and 3 risk types x 400 cases.
