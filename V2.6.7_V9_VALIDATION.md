## Field bugs locked by regression

1. **One-period Excel vs persistent risk**
   - Exact field file: `greennode_test_30000_assets_2026-08.xlsx`
   - 30,000 assets, 1 valuation period (2026-08-31), 1,200 current risk records.
   - Query `tài sản nào phát sinh 2 kỳ rủi ro liên tiếp` MUST return insufficient-period evidence and zero rows.
   - It MUST NOT reuse the 1,200 current risks as persistent risks.

2. **Dynamic province + active risk filter**
   - Exact field question: `Đà Nẵng có bao nhiêu case tài sản bảo đảm rủi ro`.
   - The actual field Excel contains 300 risk cases in Đà Nẵng total.
   - With UI filter `Sai thông tin tài sản`, the expected answer is 100 cases.
   - Province names are resolved from the dataset, not hard-coded only for Hà Nội/TP.HCM.

3. **KPI / AI shared persistent-risk source**
   - KPI and natural-language persistent-risk questions use `persistentRiskService`.
   - Persistent availability is based on `VALUATION_SNAPSHOT` history only.

4. **30K performance hardening**
   - Asset projections, reporting periods and period projections are cached by dataset object using `WeakMap`.
   - AI planner reuses period assets already projected by the UI.
   - Large-map location filtering/province summaries are memoized.

5. **Range mode period alignment**
   - AI default period is `reportingPeriod` in single-period mode and `toPeriod` in range mode.
